# Padre Paulo Ricardo Course Downloader

This project automates the download of **course materials (audio + text summaries)** from the website [padrepauloricardo.org](https://padrepauloricardo.org) using Selenium and BeautifulSoup.

The downloader supports:  
- ✔ Automatic login using saved cookies  
- ✔ Downloading a **single course**  
- ✔ Downloading **all platform courses**  
- ✔ Extracting and formatting lesson text into `.txt` files  
- ✔ Downloading class audio files  
- ✔ Organized folder output per course  
- ✔ Detailed logging of all operations  

## 🚀 Features
- Automated login with `credentials.json`
- Cookie persistence for faster subsequent access
- Per-course directory creation
- Extraction and formatting of lesson summaries
- Audio downloads triggered automatically
- Logging to `downloads/log.txt`
